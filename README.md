## 关于我

我是一名热爱 2D 游戏的独立开发者。我喜欢把自己喜欢的游戏拆开研究，理解背后的实现原理，再用代码亲手复刻出来（recode），并把所有项目开源、免费分享给社区。

- 🎮 **热爱：** 2D 游戏、像素风、经典横版与动作玩法
- 🔧 **正在做：** 游戏复刻、机制还原、引擎与工具实验
- 🌱 **理念：** 通过亲手复刻真实的游戏来学习技术
- 🎁 **分享：** 所有项目开源、完全免费，欢迎自由学习与使用
- 🤝 **合作：** 欢迎一起交流 2D 游戏开发与复刻

> 把喜欢的游戏亲手复刻一遍，是我学习技术最开心的方式。
